# MetalWar

Telegram WebApp-игра с HTTP API и живым миром поверх WebSocket.

## Эксплуатация

* [План устойчивости сервера при 100 одновременных игроках](docs/server-load-plan.md)
## Экономика и события

Переменные в Railway → Variables (все необязательные):

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `MOB_GUARD` | `shadow` | Проверка боя с мобами: `off`, `shadow` (считать отказы в `/metrics`, не мешать игре), `on` (отклонять) |
| `MOB_DPS_K` | `12` | Запас бюджета урона в секунду; увеличь, если в `mobguard.reject.low_damage` попадают честные игроки |
| `ADMIN_IDS` / `MOD_IDS` | пусто | Telegram id администраторов и модераторов через запятую — надёжнее username. Без них username из `ADMIN_USERNAMES`/`MOD_USERNAMES` закрепляется за id, который первым вошёл с ним (в `meta.role_pins`); чтобы передать права другому аккаунту, задай `ADMIN_IDS` |
| `INITDATA_MAX_AGE` | `86400` | Сколько секунд действует вход из Telegram (initData). Дольше игрок видит «Сессия устарела» и открывает игру заново |
| `SAVE_GUARD` | `shadow` | Проверка сохранений: `off`, `shadow` (только лог и `/metrics`), `on` (сохранение со скачком не принимается). Пока стоит `shadow`, подделанные ресурсы попадают в базу |
| `CRAFT_DAILY_MAX` | `20` | Сколько вещей игрок может собрать на сервере за сутки (собранное продаётся за GRAM). `0` — без лимита |
| `LOOT_FULL_KILLS` | `2500` | Убийств в сутки с полным шансом ценного лута |
| `LOOT_LOW_KILLS` / `LOOT_FLOOR` | `6000` / `0.2` | К этому числу убийств шанс плавно падает до этой доли |
| `CHIPWAR_SCHEDULE` | `tue 19:00, sat 18:00` | Расписание Chip War по Москве (`CHIPWAR_TZ_OFFSET=3`) |
| `CHIPWAR_MINUTES` / `CHIPWAR_TARGET` | `20` / `900` | Длительность и очки до победы |

Всё, что меняет GRAM, предметы, сферы и лоты, делается атомарными запросами (`db_atomic.py`, `gram.move`,
`items.take_spheres`, `items.set_item_status`): запросы к базе идут параллельно в потоках `db.py`.
